# Medicarems

Create a professional, modern Hospital Management System website called "MediCare HMS" for my BSc Computer Science college mini-project.

Make the design clean and attractive, using a blue-and-white hospital theme, a left sidebar, dashboard cards, tables, and simple forms.

Create these pages:

Dashboard with total patients, doctors, appointments and revenue.

Patients: add, view, edit and delete patient records.

Doctors: add and view doctors with their specializations.

Appointments: book appointments and update their status.

Pharmacy: manage medicine names, stock quantities and expiry dates.

Billing: create bills, calculate totals and print invoices.

Requirements:

Make the website responsive for laptop and mobile.

Use a real persistent database so records remain saved after refreshing the page.

Use fictional sample data only.

Make the navigation, forms, search and buttons functional.

Include appropriate form validation and clear error messages.

Keep the project simple enough for a beginner to understand and demonstrate.

Use the easiest supported database and hosting setup.

Build the initial dashboard and patient management page first, then continue with the other modules.

Do not pretend that a feature works if it has not been implemented.
